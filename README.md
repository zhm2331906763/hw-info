# HW-info 资产管理系统

快速批量收集电脑硬件信息，集中管理资产。客户端免安装，单 exe 运行，数据通过 Web 界面查看和管理。

---

## 一、快速开始（5 分钟上手）

### 服务端部署

在一台常开机的 Windows 电脑上部署服务端：

```cmd
# 方式一：控制台模式（双击或命令行运行，显示托盘图标）
HW-info-svr.exe -svr

# 方式二：安装为 Windows 服务（开机自启，后台运行）
HW-info-svr.exe -install
```

启动后浏览器访问 **http://本机IP:51528** 即可打开管理后台。

### 客户端运行

将 `HW-info-svr.exe` **复制一份**，重命名为 **`HW-info-192168100200.exe`**（把服务器 IP 转换为十进制数字），然后拷贝到目标电脑上双击运行。

> **IP 转十进制方法：** 例如服务器 IP 是 `192.168.1.100`：
> ```
> 192×16777216 + 168×65536 + 1×256 + 100 = 3232235876
> ```
> 重命名为 `HW-info-3232235876.exe` 即可。
>
> 如果偷懒不想算，直接运行 `HW-info-svr.exe --ip 192.168.1.100` 也行。

客户端启动后会显示硬件信息，填写 **姓名** 和 **位置** 后点击「提交」即可。

## 二、服务端详解

### 运行模式

| 命令 | 说明 |
|---|---|
| `HW-info-svr.exe -svr` | 启动服务端，显示系统托盘图标 |
| `HW-info-svr.exe -install` | 安装为 Windows 服务（开机自启） |
| `HW-info-svr.exe -uninstall` | 卸载 Windows 服务 |
| `HW-info-svr.exe -svr -service` | 以 Windows 服务模式启动 |
| `HW-info-svr.exe -tray` | 仅显示系统托盘图标 |

### 安装为 Windows 服务

```cmd
# 以管理员身份运行：
HW-info-svr.exe -install

# 然后可以在服务管理（services.msc）中找到 "HW-info 资产管理服务"
# 或通过托盘图标右键菜单管理
```

**卸载服务：**
```cmd
HW-info-svr.exe -uninstall
```

### 系统托盘图标

运行 `-svr` 后，任务栏右下角会出现托盘图标，右键菜单包含：

- **打开 Web 管理界面** — 在浏览器打开管理后台
- **启动/停止/重启服务** — 管理服务状态
- **开机自启动** — 设置托盘程序随系统自动启动

### 数据存储

所有数据自动保存在 `HW_info.db`（SQLite 数据库），与 exe 同目录。备份此文件即可备份所有数据。

### 端口说明

服务端使用 **UDP 51528** 和 **HTTP 51528** 端口，客户端通过 UDP 提交数据，自动回退到 HTTP。

## 三、客户端详解

### 客户端是什么？

客户端和服务端是 **同一个 exe 文件**。系统通过 **文件名** 或 **命令行参数** 来区分运行模式：

- 文件名包含 `-svr` → 服务端模式
- 文件名 **不包含** `-svr` → 客户端模式

### 部署客户端到员工电脑

**方式一：通过文件名配置 IP（推荐，批量部署用）**

把服务端的 `HW-info-svr.exe` 复制一份，按以下规则重命名：

```
HW-info-<IP十进制数字>[-app].exe
```

| 文件名 | 效果 |
|---|---|
| `HW-info-3232235876.exe` | 提交到 192.168.1.100 |
| `HW-info-3232235876-app.exe` | 提交到 192.168.1.100，同时收集已安装软件列表 |

**IP 转十进制换算表（常见内网段）：**

| IP 地址 | 十进制数字 |
|---|---|
| `192.168.1.1` | 3232235777 |
| `192.168.1.100` | 3232235876 |
| `192.168.1.200` | 3232235976 |
| `10.0.0.1` | 167772161 |
| `172.16.0.1` | 2886729729 |

> **小技巧：** 不想算的话，在服务端的托盘右键菜单点「配置客户端」，输入 IP 即可自动生成重命名的 exe。

**方式二：命令行参数（适合临时用或脚本调用）**

```cmd
# 启动客户端图形界面，指定服务器 IP
HW-info-svr.exe --ip 192.168.1.100

# 启动客户端并收集软件列表
HW-info-svr.exe --ip 192.168.1.100 -app

# 静默提交（不显示界面，适合脚本批量执行）
HW-info-svr.exe --ip 192.168.1.100 --name 张三 --addr 3楼会议室 --desc 联想笔记本

# 静默提交 + 收集软件列表
HW-info-svr.exe --ip 192.168.1.100 -app --name 张三 --addr 3楼会议室
```

### 客户端图形界面操作

双击客户端 exe 后，界面会显示：

1. **硬件信息区** — 自动读取本机硬件信息（只读）
2. **姓名** — 必填，使用者姓名
3. **位置** — 必填，如「3楼-财务部-工位A12」
4. **备注（可选）** — 补充说明
5. **提交按钮** — 点击后数据发送到服务端

> 客户端自动通过 UDP 发送数据，如果 UDP 不通（如跨网段），会自动切换到 HTTP 方式重试。

### 客户端收集的信息

| 信息项 | 说明 |
|---|---|
| 计算机名、用户名 | 系统基本信息 |
| 操作系统、安装日期 | Windows 版本与安装时间 |
| 主机型号、序列号 | 从 BIOS/注册表读取 |
| CPU、主板、内存 | 处理器、主板型号、内存容量 |
| 硬盘 | 型号与容量 |
| 显卡、显示器 | 独立显卡型号、显示器名称（从 EDID 读取） |
| 网卡、IP 地址、MAC 地址 | 网卡名称、IPv4 地址、物理地址 |
| 打印机 | USB 连接的打印机列表 |
| 应用程序（可选） | 添加 `-app` 参数时收集已安装软件列表 |

## 四、Web 管理后台

浏览器访问 `http://服务端IP:51528`

### 功能说明

**机器列表页：**
- 顶部统计卡片：总记录数、在线机器数、今日新增
- 数据表格：默认显示计算机名/用户名/OS/型号/序列号/CPU/主板/内存/硬盘/显卡
- **列显示按钮**：可自由切换显示/隐藏列
- **导出 CSV**：导出全部数据（含所有列，不受隐藏影响）
- **历史按钮**：点击某台机器的「历史」按钮，查看该机器的所有提交记录和配置变更

**变更记录页：**
- 记录每台机器硬件配置的变化
- 显示：变更时间、计算机名、变更字段、旧值、新值
- 例如：内存从 `8GB` 升级到 `16GB`，会自动记录

### CSV 导出

点击「导出 CSV」按钮下载全部数据，用 Excel 打开即可做进一步分析。

## 五、常见问题

**Q：客户端提交失败？**
A：检查服务端是否已启动、防火墙是否放行 51528 端口。客户端会先尝试 UDP，失败后自动用 HTTP 重试。

**Q：跨网段无法提交？**
A：广播 UDP 只能在同网段工作。跨网段时，客户端必须用 `--ip` 参数或文件名中指定具体的服务端 IP 地址。

**Q：如何备份数据？**
A：备份 `HW_info.db` 文件即可，所有数据都在里面。

**Q：如何更新服务端？**
A：停止服务 → 替换 exe 文件 → 启动服务。`HW_info.db` 数据文件不会丢失。

**Q：一台机器提交了多次，数据会重复吗？**
A：每次提交都会保存为新记录（保留历史）。Web 页面「机器列表」默认显示每台机器的最新数据，「全部数据」显示所有历史记录。

## 六、技术架构

```
┌──────────────┐     UDP/HTTP      ┌──────────────────┐
│  客户端 exe   │ ────────────────→ │  Windows 服务/Host │
│  (员工电脑)   │                   │  (服务器)          │
└──────────────┘                   │                   │
                                   │  ┌─────────────┐  │
                                   │  │  SQLite DB   │  │
                                   │  └─────────────┘  │
                                   │                   │
                                   │  HTTP API :51528  │
                                   └───────┬───────────┘
                                           │
                                   ┌───────▼───────────┐
                                   │  Web 管理后台      │
                                   │  (浏览器访问)      │
                                   └───────────────────┘
```

- 语言：C# / .NET Framework 4.8
- 数据存储：SQLite
- Web 服务：内嵌 HttpListener（无 IIS 依赖）
- 前端：纯静态 HTML/CSS/JS（Bootstrap 5 风格）
