# HW-info 硬件资产管理系统

快速批量收集局域网内电脑的硬件配置信息，集中管理资产。服务端为单文件程序（exe），自带 Web 管理后台，支持 Windows 服务安装、系统托盘、硬件变更追踪、CSV/XLSX 导出。

---

## 功能特性

- **硬件信息采集**：计算机名、用户名、操作系统、主机型号、序列号、CPU、主板、内存、硬盘、显卡、显示器、打印机、网卡、IP/MAC 地址等
- **Web 管理后台**：现代化管理界面，机器列表、机器详情、变更记录一目了然
- **变更追踪**：每次客户端提交自动对比上次配置，记录硬件变更（旧值 → 新值）
- **CSV / XLSX 导出**：一键导出全部机器最新数据，表格自动换行显示多个硬件
- **Windows 服务**：支持安装为系统服务并开机自启
- **系统托盘**：托盘图标快速管理服务、打开 Web 后台、查看使用说明
- **单文件部署**：所有依赖（含 SQLite 原生组件）已内嵌到 exe 中，复制即用

## 快速开始

### 服务端部署

在常开的 Windows 电脑上，双击 `HW-info-svr.exe`，选择：

| 按钮 | 功能 |
|---|---|
| ▶ 启动服务器 | 启动服务端并显示系统托盘图标 |
| ⏺ 安装服务(开机自启) | 安装为 Windows 服务，随系统自动启动 |
| ✕ 卸载服务 | 卸载 Windows 服务 |

启动后浏览器访问 **`http://本机IP:51528`** 即可打开管理后台。

> 提示：也可以通过命令行 `HW-info-svr.exe -install` 直接安装服务，或用 `-svr` 启动。

### 客户端部署

客户端与服务端是**同一个 exe**，通过文件名或命令行参数区分运行模式：

**方式一：重命名 exe（推荐批量部署）**

把 `HW-info-svr.exe` 重命名为 `HW-info-<IP十进制数字>[-app].exe` 再分发到员工电脑。

| 文件名 | 效果 |
|---|---|
| `HW-info-3232235876.exe` | 提交到 192.168.1.100 |
| `HW-info-3232235876-app.exe` | 提交到 192.168.1.100，同时收集软件列表 |

**IP 转十进制示例**：`192.168.1.100` → `192×16777216 + 168×65536 + 1×256 + 100` → `3232235876`

**方式二：命令行参数**

```cmd
:: 客户端图形界面
HW-info-svr.exe --ip 192.168.1.100

:: 收集软件列表
HW-info-svr.exe --ip 192.168.1.100 -app

:: 静默提交（脚本批量使用）
HW-info-svr.exe --ip 192.168.1.100 --name 张三 --addr 3楼会议室 --desc 备注
```

---

## 命令行参数

| 参数 | 说明 |
|---|---|
| `-svr` | 启动服务端（带托盘图标） |
| `-install` | 安装 Windows 服务 |
| `-uninstall` | 卸载 Windows 服务 |
| `-tray` | 仅显示系统托盘图标 |
| `--ip <IP>` | 指定服务器 IP（客户端） |
| `-app` | 同时收集软件安装列表 |
| `--name <姓名> --addr <位置> [--desc <备注>]` | 客户端静默提交 |

## 管理后台说明

### 机器列表

- 顶部统计：总记录数、已收集机器数、今日新增
- 默认显示：计算机名、用户名、型号、CPU、主板、内存、硬盘、显卡等
- 「☰ 列显示」可切换显示/隐藏列（含数量列、序列号、操作系统等）
- 搜索框按计算机名或用户名筛选
- 分页显示，每页 20/50/100 条可选
- 点击任意行进入该机器详情页

### 机器详情

- 当前配置：该机器最新一次提交的全部硬件信息
- 提交历史：默认折叠，点击展开查看所有历史提交
- 变更记录：该机器历次硬件变更（时间、字段、旧值 → 新值）

### 变更记录

全局查看所有机器的硬件变更历史。

### 数据导出

- **CSV**：导出全部机器最新数据，Excel 可直接打开
- **XLSX**：导出为 `硬件资产信息表-日期.xlsx`，单元格自动换行显示多硬件、含数量列

## 数据存储

所有数据保存在 exe 同目录的 **`HW_info.db`**（SQLite 数据库）。备份该文件即可备份全部数据。

---

## 开发说明

- 语言：C# / .NET Framework 4.8
- UI：WinForms（托盘/配置窗口）+ 内嵌 HttpListener + 纯静态 Web 前端
- 数据库：SQLite（System.Data.SQLite）
- 导出：ClosedXML
- 构建：Visual Studio / MSBuild，x64

### 构建

```cmd
msbuild HW_info\HW_info.csproj /p:Configuration=Release
```

产物输出到 `HW_info\bin\Release\`，其中 `HW-info-svr.exe` 为单文件可执行程序（依赖已内嵌）。
